02. What Is CSS?

CSS stands for Cascading Style Sheets. It controls the appearance and layout of a webpage. It helps us change colors, fonts, spacing, borders and more.

CSS Properties

Color - Changes text color.
Background-color - Changes background color.
Font-family - Changes the font.
Font-size - Changes text size.
Border - Adds a border.
Padding - Creates space inside the border.
Margin - Creates space outside the border.
Text-align - Aligns the text.

03. Three Ways to Style HTML

1. Inline CSS

Inline CSS uses the style attribute inside an HTML element.

Example:
<h1 style="color:blue;">Hello</h1>

2. Internal CSS

Internal CSS uses the <style> element inside the <head> section.

Example:
h1 { color: green; }

3. External CSS

External CSS uses a separate .css file connected using the <link> element.

Example:
<link rel="stylesheet" href="style.css">

04. Color Values

Colors can be set using different formats:

Color Name: Tomato
HEX: #1e90ff

RGBA: rgba(255, 99, 71, 0.5)
HSLA: hsla(180, 100%, 50%, 0.5)
